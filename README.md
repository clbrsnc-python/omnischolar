# OmniScholar - Universal Scholarly Search Engine

OmniScholar is a light-themed, high-performance academic search application that queries 9 major open-access scholarly repositories simultaneously.

## Features
- **9 Target Repositories**: OpenAlex, CORE Aggregator, arXiv, DOAJ, DOAB, Europe PMC, Unpaywall, Semantic Scholar, and Scopus OA.
- **Advanced Query Builder**: Boolean logic rows (AND, OR, NOT) with field scoping (Title, Author, Abstract, DOI/ISSN).
- **Direct Launchers**: Google Scholar, BASE Search, Shodhganga ETDs, and WorldCat.
- **Faceted Refinement**: Filter by year, document type, peer-reviewed status, and language.
- **Scopus Integration**: Step-by-step guidance modal & key saving.
- **Citation & Reference Generator**: Formats APA 7th, MLA 9th, Chicago 17th, IEEE, Harvard, and BibTeX with export downloads.
